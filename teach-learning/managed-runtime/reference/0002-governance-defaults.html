Governance-Defaults

Default Environment Group von Copilot Managed Runtime: Werte, Pfade, Audit. Quelle: Learn: Governance, Learn: Security & compliance.

Grundregeln

  • Default Environment Group: von Microsoft verwaltet, Scope «Everyone», nicht löschbar.
  • Routing in Personal Environments: permanent, nicht abschaltbar.
  • Microsoft-Regel editieren = keine automatischen Microsoft-Updates mehr für diese Regel.
  • Öffnen einer App = Mitglied der Environment-Sicherheitsgruppe und App-Zugriff.
  • Ändern erfordert eine Manage-Rolle. Read-only-Rollen sehen die Einstellungen nur.

Offen: «Hochstufen» von Apps

Annahme, nicht geklärt: Braucht eine App mehr als die Default Group erlaubt, wird sie in ein gemeinsames Environment mit lockererer Gruppe gebracht, statt das Personal Environment zu lockern. Belegt ist nur: ms app create --environment-id erlaubt ein anderes Ziel-Environment (dort CLI-Erstellung freigeben). Das erzeugt eine neue App mit neuer ID und URL; Verschieben gibt es nicht. CSP-Defaults

default-src 'self' · script-src 'self' <platform> · style-src 'self' 'unsafe-inline'
connect-src 'self' · img-src 'self' data: · media-src 'self' data: · font-src 'self'
frame-src 'self' · child-src 'none' · worker-src 'none' · object-src 'self' data:
form-action 'none' · base-uri 'self' · manifest-src 'none' · frame-ancestors 'self' <platform>

Eigene Werte werden mit den Defaults zusammengeführt. Ein Default von 'none' wird dabei ersetzt. Keine Wildcards und kein 'unsafe-inline' für Scripts. Connector-Calls brauchen keinen CSP-Eintrag.
