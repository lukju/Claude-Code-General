# Vorwissen: erfahrener Softwareentwickler, CMR neu

Der User gibt an, Software entwickeln zu können; Entwicklung ist «nicht das Thema #1». SPA-, npm-, Git- und CLI-Konzepte nicht erklären. Neu sind die Plattform-Konzepte von CMR (Host, Governance, Environments, Abrechnung), dort startet die Zone der proximalen Entwicklung.

**Evidence**: Aussage beim Start von `/teach` am 23.11.2026.
