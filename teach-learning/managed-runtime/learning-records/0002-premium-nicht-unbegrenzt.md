# Korrigiert: Power Apps Premium heisst nicht «unbegrenzt gratis»

Der User nahm an, mit Power Apps Premium fielen unabhängig von der Last keine Kosten an. Tatsächlich verbrauchen Premium-Nutzer keine Copilot Credits, ihre API-Calls zählen aber gegen die täglichen Power Platform Request Limits. Nutzung darüber sowie spezialisierte Dienste wie Work IQ APIs werden über Copilot Credits abgerechnet. Relevant für spätere Kosten-Lektionen: Lastszenarien gegen Request Limits rechnen.

**Evidence**: Frage im Chat am 23.11.2026; Quelle: [Licensing FAQ](https://learn.microsoft.com/en-us/microsoft-365/admin/manage/apps/licensing-faq?view=o365-worldwide).
